# ❌⭕ XO Game

لعبة إكس أو بسيطة بـ PWA

## 📲 التثبيت على الفون

### طريقة 1: PWA (الأسهل)
1. ارفع الملفات على GitHub Pages
2. افتح الرابط من Chrome على الفون
3. من القائمة (⋮) → "إضافة للشاشة الرئيسية"

### طريقة 2: APK
1. ارفع على GitHub Pages (متاح أونلاين)
2. ادخل https://www.pwabuilder.com
3. اكتب رابط موقعك
4. حمّل APK وثبته

## 💻 محليًا
افتح `index.html` في أي متصفح.
